## 2026-06-12 - Header Accessibility and Interactivity
**Learning:** Adding ARIA attributes (aria-expanded, aria-controls, aria-haspopup) to navigation components significantly improves screen reader support, and implementing global 'Escape' key listeners enhances keyboard accessibility for all users.
**Action:** Use `useId` for stable and unique ARIA controls linking, and always include an 'Escape' key listener for dismissible UI elements like dropdowns and mobile menus.
