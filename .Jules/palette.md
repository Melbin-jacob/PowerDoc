## 2025-05-14 - Interactive Navigation Accessibility
**Learning:** Interactive navigation elements like dropdowns and mobile menus require proper ARIA state (aria-expanded, aria-controls) and keyboard listeners (Escape key) to meet accessibility standards and provide a smooth user experience.
**Action:** Always implement aria-expanded, aria-haspopup, aria-controls (with useId), and global Escape key listeners for any custom dropdown or modal-like navigation component.
